# Step 10 — CardioExplain React Frontend

This is the Vite + React JSX frontend for the existing `CVD_Explainable_ML` project.

## Where it belongs

Copy the **contents** of this `frontend/` folder into your existing:

`C:\CVD_Explainable_ML\frontend\`

Do not overwrite or delete your `backend/`, `data/`, `models/`, `notebooks/`, or `outputs/` folders.

## Requirements

- Node.js 20.19+ or 22.12+ (current Vite requirement)
- Python venv and Flask backend from Step 9
- `models/best_model.joblib` created in Step 5
- `outputs/metrics/model_comparison.csv` generated by `python src/train_model.py`

## Install and run

**Terminal 1, from the project root:**

```powershell
.\venv\Scripts\Activate.ps1
python backend/app.py
```

**Terminal 2:**

```powershell
cd C:\CVD_Explainable_ML\frontend
npm install
npm run dev
```

Open http://127.0.0.1:5173

If you want the standard Vite generator instead, run `npm create vite@latest . -- --template react` inside an **empty** frontend folder, then copy `src/` and other files from this package over the scaffold. Do not run that command on top of this package unless you intend to replace files.

## API integration

- `/health` — connection status
- `/api/predict` — patient prediction
- `/api/explain` — SHAP and LIME explanation
- `/api/metrics` — model scores, class metrics, confusion matrix

Backend uses `http://127.0.0.1:5000` by default. Override in `.env`:

`VITE_API_URL=http://127.0.0.1:5000`

Restart Vite if you change `.env`.

## Important

- Example form entries mirror one row of the user's example dataset, not a validated medical case.
- Class labels remain Class 0 and Class 1 until target mappings are verified from the source dataset.
- Explanations are different scales: SHAP = log-odds, LIME = local probability surrogate weights.
- Metrics come from Flask. A missing `outputs/metrics/model_comparison.csv` will show an API error; run `python src/train_model.py` from the main project folder to regenerate.
- Current `/api/metrics` does not provide ROC curve coordinates; the notebook-created image is in `outputs/figures/roc_curve.png`.
- Do not use for clinical diagnosis or treatment.
